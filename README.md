# AI-Powered Intrusion Detection Solution (CLO4)

## CLO4 Alignment
**Course CLO4**: Create solutions to real-life scenarios using different security-related tools.

This project delivers an ML-based Network Intrusion Detection System (NIDS) proof-of-concept for a realistic enterprise scenario at **SecureNet Corp.**

## Real-World Scenario
SecureNet Corp.'s CISO requested a proactive IDS enhancement because signature-based firewalls can miss zero-day or behaviorally novel attacks.  
The mission is to classify network traffic as **Benign (Normal)** or **Malicious (Attack)** and analyze security implications (especially false negatives).

## Dataset
- **Dataset**: CIC-IDS2017
- **Why this dataset**: It contains realistic enterprise attack traffic and benign traffic, including DDoS, Brute Force, Infiltration, Web Attacks, Bot, SSH-Patator, and FTP-Patator.
- **Download links**:
  - Official: https://www.unb.ca/cic/datasets/ids-2017.html
  - Community mirror: https://www.kaggle.com/datasets/cicdataset/cicids2017
- **Placement**: Put the merged CSV file at `data/CIC_IDS2017.csv`

## Repository Structure
- `IDS_ML_Solution.ipynb` — complete 14-section end-to-end workflow
- `requirements.txt` — pinned dependencies
- `data/dataset_info.txt` — dataset setup instructions
- `models/` — serialized model artifacts (generated by notebook)
- `results/` — metrics and visualization outputs (generated by notebook)

## Installation & Setup
```bash
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
.venv\Scripts\activate     # Windows (PowerShell/CMD)
pip install -r requirements.txt
```

## Run the Notebook
```bash
jupyter notebook IDS_ML_Solution.ipynb
```

Run all cells in order to generate:
- Trained model artifacts in `models/`
- Evaluation summaries and plots in `results/`

## ML Models Implemented
1. **Random Forest Classifier** (feature interactions + feature importance)
2. **Neural Network (MLPClassifier)** (non-linear pattern learning)
3. **Decision Tree (optional baseline comparison)**

## Performance Summary (Example Template)
After running the notebook, fill/report generated metrics from `results/metrics_summary.csv`:
- Accuracy
- Precision
- Recall (security-critical)
- F1-Score
- ROC-AUC
- Specificity

> Note: The Decision Tree is intentionally included as a simple baseline and may underperform in IDS contexts (higher missed-attack risk). For deployment-oriented recommendations, prioritize Random Forest and Neural Network results.

## Security Implications & Deployment Recommendations
- **High Recall Priority**: Missed attacks (false negatives) are critical failures.
- **False Positive Tradeoff**: Excessive false positives increase alert fatigue for SOC teams.
- **Operational Use**: Integrate model outputs into SIEM/SOAR pipelines for triage.
- **Governance**: Monitor model drift and retrain periodically with newer traffic.
